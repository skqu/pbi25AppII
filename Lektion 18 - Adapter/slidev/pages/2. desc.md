

# Beskrivelse

Vores system har kørt med en et betalingssytem i lang tid. Der er dog kommet et nyt, bedre og billigere betalingssystem på markedet. 
Systemet skal konvereteres til at bruge det nye betalingssystem, hvilket kræver tilpasning og ændringer i koden. 


```mermaid{scale:0.6}
sequenceDiagram
    participant Client
    participant System
    participant OldPayment

    Client ->> System : Pay(orderId, amount)
    System ->> OldPayment : VerifyCard()
    OldPayment -->> System : verification
    System ->> OldPayment : CreateTransaction(user, value, currency)
    OldPayment -->> System : PaymentStatus
    System ->> OldPayment : VerifyPayment()
    OldPayment -->> System : verification
    System -->> Client : Result
```
