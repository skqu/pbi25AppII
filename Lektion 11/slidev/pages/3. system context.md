

# System Context

Ovordnet diagram, som viser interaktion mellem bruger og systemer. \
Tiltænkt til ikke teknisk. 

### Scope
Et enkelt software system

### Primary elements
Systemet vi undersøger

### Supporting elements
Bruger som interagere med systemet, samt eksterne system afhængigheder. 

### Intended audience
Kan bruges ekstern som intern i udviklingsteamet. Dette diagram kan bruges til ekstern kommunikation.
