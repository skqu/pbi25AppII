# Stored Function

::left::

En stored function ligger også i DBMS'et og bruges til at beregne værdier.

<v-clicks>

- Returnerer altid én værdi
- Kan bruges i SELECT statements
- God til genbrug af beregninger
- Må ikke ændre data (i praksis)

</v-clicks>

## Definition

En stored function:
- har 0..* parametre
- **skal returnere én værdi**
- bruges ofte i queries (SELECT)

::right::


````md magic-move {lines: true}
```ts
// Create function
DELIMITER $$

CREATE FUNCTION GetLoanCount()
RETURNS INT
DETERMINISTIC
BEGIN
  RETURN 0;
END $$

DELIMITER ;
```

```ts
//Content
DELIMITER $$

CREATE FUNCTION GetLoanCount()
RETURNS INT
DETERMINISTIC
BEGIN
  DECLARE loanCount INT;

  SELECT COUNT(*) INTO loanCount
  FROM Loan;

  RETURN loanCount;
END $$

DELIMITER ;
```

```ts
// Input
DELIMITER $$

CREATE FUNCTION GetLoanCountByUser(p_UserId INT)
RETURNS INT
DETERMINISTIC
BEGIN
  DECLARE loanCount INT;

  SELECT COUNT(*) INTO loanCount
  FROM Loan
  WHERE UserId = p_UserId;

  RETURN loanCount;
END $$

DELIMITER ;
```

```ts
// Multiple input
DELIMITER $$

CREATE FUNCTION GetLoanCountByUserAndDate(
  p_UserId INT,
  p_FromDate DATE,
  p_ToDate DATE
)
RETURNS INT
DETERMINISTIC
BEGIN
  DECLARE loanCount INT;

  SELECT COUNT(*) INTO loanCount
  FROM Loan
  WHERE UserId = p_UserId
    AND LoanDate BETWEEN p_FromDate AND p_ToDate;

  RETURN loanCount;
END $$

DELIMITER ;
```

```ts
// Use function
SELECT GetLoanCountByUser(1);

SELECT 
  UserId,
  GetLoanCountByUser(UserId) AS LoanCount
FROM Loan;
```
````
