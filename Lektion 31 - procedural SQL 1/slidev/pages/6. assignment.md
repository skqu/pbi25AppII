

# Opgave 1: Migrere til MySql

Erstat in memory med MySql

1) Add Package (provider)[https://learn.microsoft.com/en-us/ef/core/providers/?tabs=dotnet-core-cli]
```sh
dotnet add package Pomelo.EntityFrameworkCore.MySql

```

1) Ændre Program.cs til: 

```c#
string connectionString = @"Server=localhost; User ID=root; Database=code_procedural";

// Add different services

builder.Services.AddDbContext<LibraryContext>(options => options.UseMySql(connectionString, ServerVersiong.AutoDetect(connectionString)));
```

1) Initializere database

```sh
dotnet ef migrations add Init
dotnet ef database update
```
1) Test

# Opgave 2: Lav en stored Procedure

1) Initializere procedure

```sh
dotnet ef migrations add sp-PRocedureName
```

1) Skriv koden i /migrations/sp-PRocedureName.cs

1) Tilføj koden til up. 

1) Opdatere database

```sh
dotnet ef database update
```
