


# Stored procedure

::left::

En stored procedure ligger i DBMS'et, altså tæt på data.

<v-clicks>


- Hurtigere eksekvering
- Mindre netværkstrafik
- Samler logik i databasen
- Kan være lettere at vedligeholde

</v-clicks>

## Definition


En stored procedure:
- kan have 0..* parametre
- returnerer ikke nødvendigvis en værdi
- kan læse og ændre data i databasen

::right::

```ts
// Content
DELIMITER $$

CREATE PROCEDURE GetLoans()
BEGIN
  SELECT * FROM Loan;
END $$

DELIMITER ;
```
```ts
// Input
DELIMITER $$

CREATE PROCEDURE GetLoans(IN p_UserId INT)
BEGIN
  SELECT * FROM Loan WHERE UserId = p_UserId;
END $$

DELIMITER ;
```
```ts
// Multiple inputs
DELIMITER $$

CREATE PROCEDURE GetLoansByUserAndDate(
  IN p_UserId INT,
  IN p_FromDate DATE,
  IN p_ToDate DATE
)
BEGIN
  SELECT *
  FROM Loan
  WHERE UserId = p_UserId
    AND LoanDate BETWEEN p_FromDate AND p_ToDate;
END $$

DELIMITER ;
```
```ts
// Output
DELIMITER $$

CREATE PROCEDURE CountLoansByUser(
  IN p_UserId INT,
  OUT p_LoanCount INT
)
BEGIN
  SELECT COUNT(*)
  INTO p_LoanCount
  FROM Loan
  WHERE UserId = p_UserId;
END $$

DELIMITER ;

// Call with output
CALL CountLoansByUser(1, @count);
SELECT @count;
```
