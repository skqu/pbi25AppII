# Views

En virtuel tabel som kan kaldes med SELECT. 
- Konstrueret ved hver kald. 
- Restrict access baseret på rolle. 

````md magic-move {at: 1, lines: true}
```sql
    CREATE VIEW view_name AS SELECT query
```

```sql
   CREATE VIEW UserLoans AS
    SELECT 
        l.BookId,
        l.CopyNumber,
        u.Name, 
        l.UserId
    FROM Loans l
    JOIN Users u ON l.UserId = u.Id;

    SELECT * FROM UserLoans WHERE UserID == sp_UserId;
```
````
