## Løsningsforslag

```mermaid{scale:0.5}
sequenceDiagram
    Frontend ->> Backend : Hashing(username, password)
    activate Backend
    Backend ->> Backend : Logning
    Backend -->> Frontend : Hashed password
    deactivate Backend
    Frontend ->> Backend : Validering(username, hPass)
    activate Backend
    Backend ->> Database : Opslag(username, password)
    Database -->> Backend : bruger
    Backend ->> Backend : Logning
    Backend -->> Frontend : Result
    deactivate Backend
    Frontend ->> Backend : Token Generering
    activate Backend
    Backend ->> Backend : Logning
    Backend -->> Frontend : Token
    deactivate Backend
```


::right::

## Problemet

Problemer med denne tilgang
- Stærk kobling mellem frontend og validering. 
- Hvis der er noget som skal ændres, kræver det mange tilpasninger. 
- Security issue, hvis udstiller kontinuerlig data på vores kommunikations linje.
