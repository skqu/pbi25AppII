
# Case 2

::left::

## Login-proces
Login kræver: 
- Validering
- Hashing
- Databaseopslag
- Token Generering
- Logning

Frontend skal bare kalde:
```c#
Login(username, password)
```
::right:: 

## Problemet
Hvis frontend selv kalder alle delene:
- Kompleksitet spredes
- Høj kobling
- Svært at ændre backend

## Behov
Vi ønsker:
- Én simpel indgang
- Intern kompleksitet skjules
- Tydeligt interface
