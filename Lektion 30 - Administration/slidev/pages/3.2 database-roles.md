# Database roller


## DA vs DBA

| DA | DBA |
|----|--------|
| Stratetisk planlægning | Kontroller og supervisere |
| Long-term målsætning  | Eksekvere målsætning |
| Sætter politikker og standarder  | Sikre politiker og procedure |
| Bred scope | Indsnævret scope |
| Long-term fokus | Daglig drift |
| Ledelse tilgang | teknisk tilgang |
| Teknologi uafhængig | Teknologi afhængig |
