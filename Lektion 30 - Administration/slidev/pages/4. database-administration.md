# Database administration

Oprettelse af brugere og håndhævelse af sikkerhedspolitikker

Fokus:

- Hvordan DBA opretter brugere
- Hvordan roller anvendes
- Hvordan politikker håndhæves i databasen

## Formål

En Database Administrator (DBA) skal:

- Administrere brugere
- Styre adgang til databasen
- Sikre datasikkerhed
- Implementere virksomhedens politikker
- Overvåge databaseaktiviteter

## Scenario

En ny medarbejder starter i virksomheden.

Brugeren skal:

- Have adgang til databasen
- Kun kunne læse kundedata
- Følge virksomhedens passwordpolitik

## Opret en bruger

```sql 
CREATE USER anna
IDENTIFIED BY "Start123!";
```

### Forklaring
CREATE USER opretter ny databasebruger

IDENTIFIED BY sætter adgangskode

## Håndhævelse af politik

```sql
CREATE PROFILE secure_profile LIMIT
PASSWORD_LIFE_TIME 180
PASSWORD_REUSE_TIME 365;
ALTER USER anna PROFILE secure_profile;
```

## Opret roller
Brugeren skal kun kunne læse data.
```sql
GRANT SELECT
ON customers
TO customer_reader;
```
Resultat

Rollen kan nu:

1) Læse kundedata
1) Ikke ændre eller slette data

### Tildel rolle til bruger

```sql
GRANT customer_reader TO anna;
```

Brugeren får nu:

1) Læseadgang
1) Ingen skriveadgang
1) Ingen administratorrettigheder

## Kontrol og sikkerhed

DBA skal løbende:

1) Overvåge loginforsøg
1) Fjerne gamle brugere
1) Revidere roller
1) Kontrollere privilegier

```sql
SELECT * FROM DBA_USERS;
```

## Best Practice

1) Brug roller fremfor individuelle rettigheder
1) Giv mindst mulige adgang
1) Brug password policies
1) Overvåg databaseaktivitet
1) Dokumentér ændringer
