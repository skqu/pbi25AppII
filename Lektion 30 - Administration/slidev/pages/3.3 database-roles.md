# Database roller


## Eksempel

Ud fra politikker -> Retning skal der udvikles standarder -> strategi som bruges til at definere procedure -> implementering. 


| Kategori | Beskrivelse |
| ----- | ----- |  
| Politik | Alle bruger skal have kodeord |
| Politik | Kodeord skal skiftes ½ år |
| Standarder | Kodeord skal have 5 character |
| standarder | Kodeord må maks have 12 character |
| Procedure |  1) For at oprette en kodeord, skal bruger sende forspørgelse om konto oprettelse til DBA 2) DBA godkender forspørgelse 3) Relevant personale opretter konto med kode 4) Info sendes til bruger og DBA 5) Bruger ændre kodeord |
