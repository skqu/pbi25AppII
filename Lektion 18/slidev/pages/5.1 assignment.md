

# Opgave 2 – Implementer Observer (grundniveau)

::left::

Implementer følgende interfaces:

```c#
interface IObserver
{
    void Update();
}

interface ISubject
{
    void RegisterObserver(IObserver observer);
    void RemoveObserver(IObserver observer);
    void NotifyObservers();
}
```
::right::


## Opgave

1) Lav en klasse Order der implementerer ISubject
1) Lav en observer Log
1) Registrer Log som observer
1) Når Order.ChangeStatus() kaldes skal Log.Update() kaldes

## Test

```c#
Order order = new Order();
order.RegisterObserver(new Log());

order.ChangeStatus();
```
