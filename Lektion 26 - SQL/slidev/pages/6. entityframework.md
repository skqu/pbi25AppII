


# Entity Framework Core 



Faktisk et repository pattern mellem database og .net. Abstrahere database logik væk - så vi kan arbejde med database ved brug .net objekter. 

2 modes, testing (InMemory) og production (database)
::left::

Tilføj package og installere tilføjelser: 
1) dotnet new webapi
1) dotnet add package Microsoft.EntityFrameworkCore
1) dotnet tool install --global dotnet-ef
1) dotnet add package Microsoft.EntityFrameworkCore.InMemory

::right::

For produktion: 

1) dotnet add package [provider](https://learn.microsoft.com/en-us/ef/core/providers/?tabs=dotnet-core-cli) 
1) Lav context
1) dotnet ef migrations add InitialCreate \
Opretter database første init. 
1) dotnet ef database update \
Updatere database - hvis nødvendigt.
