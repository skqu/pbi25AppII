

# Models

Dto's var data transfer fra controllers til services. 
Models er data transfer fra services til database. 

Models er tro mod databsen - hvor DTO er tro mod hvad brugeren skal se. 

```ts
public class UserModel
{
    public string Name {set; get;} = string.Empty;
    public string Id {set; get;} = 0;
    public DateTime Created {get; set;}
}

public class UserDto
{
    public string Name {set; get;} = string.Empty;
    public string Id {set; get;}  = 0;
}

```
