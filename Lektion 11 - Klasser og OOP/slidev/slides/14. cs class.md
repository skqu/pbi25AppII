
# C# klasser

```c#

class Animal // Class
{
  /*
    Attributes
  */
  protected string _sound; // Encapsulation

  public Animal() // Constructor
  {  }
  /*
    Method
   */
  public string sound()
  {
    return _sound;
  }
  public void setSound(string newSound)
  {
    _sound = newSound;
  }
}

```
