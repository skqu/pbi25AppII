

# API 

- Interface til services
- interface mellem services
RestFull er en type API, som virker ved at modtage en request og sende et respons. 
Restfull API består af følgende to elementer: 

1)  Endpoint \
Endpoint er den url der bliver kaldt ved API. 
1) Resource \
En resource er det sidste navneord i en endpoint. 

## Eksempler: 

- /api/v1/users/1
- users
- /api/v1/institutions/educations/cohorts/students/
- cohorts
