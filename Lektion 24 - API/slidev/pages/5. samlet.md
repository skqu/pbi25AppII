
# Samlet

Vi skal lige rette lidt til i vores main fil. 
Lige nu bruger den simpleAPI - vi bruger controllers. 

1) Lav vores class Program
1) Lav vores static void Main
1) Kopier alt ind i Main

```ts{3|5-7|6,11|7|9|14}
    static void Main()
    {
        var builder = WebApplication.CreateBuilder();

        builder.Services.AddOpenApi();
        builder.Services.AddControllers();
        builder.Services.AddSingleton<PostService>();

        var app = builder.Build();

        app.MapControllers();


        app.Run();

    }
```
