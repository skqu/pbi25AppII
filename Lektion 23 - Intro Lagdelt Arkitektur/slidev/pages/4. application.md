## Hvad er en service?
Meget mere om dette på næste semester.

En service er en del af systemet, som udfører en bestemt handling eller forretningslogik.
Eksempelvis: 
- UserService
- OrderService
- etc

::right::


```ts
    public class UserService
    {
        public List<string> GetAllUsers()
        {
            // Logic lives here
            return new List<string>
            {
                "Alice",
                "Bob",
                "Charlie"
            };
        }
    }
```
